# What's new in Wisp

<!-- Add user-facing notes for the next stable release here. -->

## Improved

- If you use the Polestar guide addon, Wisp can see which guide you are following, your current step and its goals, and the next steps, so you can ask about them directly.
- Wisp can also build a guide for you in Polestar, such as a quest chain or a gathering run. Polestar tracks it and points the way, and Wisp can update it later without losing your progress.
- Wisp answers gear and upgrade questions faster: it reads your equipped items' stats in one step and spends fewer steps re-checking items.

## Fixed

- An empty orange dot no longer shows in the Wisp window header when everything is working.
- With Wisp set to Chinese, chat titles, your character and zone, and messages written with accents or ¿ (such as Spanish) now display correctly instead of showing gaps or empty boxes.
