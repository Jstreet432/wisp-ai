# Start your first chat in WoW

## New

- Select **What can you do?** in an empty WoW chat to see what Wisp can help
  with. Any draft you've already typed stays in the composer.

## Improved

- Desktop usage analytics now include which setup steps were shown and whether
  setup was finished or deferred. You can turn off usage analytics in Settings.

## Fixed

- The CurseForge download now uses the same addon version as the copy bundled
  with Wisp Desktop.
