# A simpler setup and automatic WoW addon updates

## New

- Open Wisp Desktop and connect an AI provider before setting up WoW. If your
  provider is already connected, setup can reuse that connection.
- Wisp updates the addon in your configured WoW installation after a desktop
  update. Reload WoW to start using the new addon.
- Ask Wisp about flight paths your character has discovered, current cooldowns,
  or where your Hearthstone is bound.

## Improved

- Find AI providers and game integrations in dedicated settings pages. The
  sidebar shows connection status and gives you a direct route to setup.
- App update settings make it easier to see the installed version, choose a
  release channel, and view an available update.
- Wisp can suggest a concrete follow-up after answering, such as preparing a
  macro or saving a tracker. It waits for you to accept before taking action.

## Fixed

- Wisp can start when another local app is using its preferred connection port.
- Legacy chats, routines, panels, and memory can migrate when multiple Wisp
  processes start at the same time.
