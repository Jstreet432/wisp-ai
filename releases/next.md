# What's new in Wisp

<!-- Add user-facing notes for the next stable release here. -->

## New

- Wisp now updates itself. New versions download in the background and install once WoW has been closed for 10 minutes and no reply is running, so an update never interrupts your game. If Wisp was in the tray when it updated itself, it stays there. You can turn this off in **Settings → App updates → Install updates automatically**.

## Improved

- Routines use less of your ChatGPT usage: they pause after you reach your usage limit instead of retrying every few minutes, and skip a check when nothing has changed since the last one had nothing to report.
